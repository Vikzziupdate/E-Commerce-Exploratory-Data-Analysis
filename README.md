# E-Commerce Exploratory Data Analysis

## Project Overview
This project explores an e-commerce dataset using Microsoft Excel to identify patterns in order values, product performance, order status, payment methods, and referral sources.

## Objectives
- Explore and summarize the dataset.
- Analyze order values and product performance.
- Examine order status and payment method distributions.
- Identify potential outliers using the IQR method.
- Communicate findings through charts and a report.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- PivotTables
- Charts and descriptive statistics

## Project Deliverables
- Cleaned dataset (where sharing is permitted)
- Excel analysis workbook
- Visualizations
- Exploratory data analysis report

## Data Privacy
The original dataset may contain personal customer information. Raw customer records, names, addresses, tracking numbers, and other identifying details are not included in this public repository.

## Disclaimer
Findings describe the dataset analyzed and should not be generalized beyond it without additional validation.
